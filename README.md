Windows Server Labs | Security & Infrastructure

Autor: Jose Jadiel Gomez Bautista
Área: Seguridad Informática y Ciberseguridad
Enfoque: Administración de servidores, infraestructura y hardening.

Acerca del proyecto

Este repositorio contiene documentación de prácticas y laboratorios académicos enfocados en la administración, configuración, auditoría y protección de entornos Windows Server.

El objetivo es desarrollar habilidades prácticas en infraestructura tecnológica, administración de dominios y seguridad informática.

Tecnologías y herramientas

* Windows Server 2016
* Windows Server 2022
* Windows 10
* Active Directory Domain Services (AD DS)
* DNS y Group Policy (GPO)
* PowerShell
* CIS Benchmarks
* HardeningKitty
* WSUS
* Windows LAPS
* VirtualBox

Laboratorios

01. Active Directory

* Instalación y configuración de Active Directory.
* Creación de dominios.
* Administración de usuarios y grupos.
* Organización mediante unidades organizativas (OU).

02. DNS

* Configuración de zonas DNS.
* Registros y resolución de nombres.
* Diagnóstico de problemas de conectividad.

03. Group Policy (GPO)

* Creación y administración de políticas.
* Restricciones de inicio de sesión.
* Aplicación y validación de políticas de seguridad.

04. Security Hardening

* Evaluación CIS Benchmark.
* Auditoría con HardeningKitty.
* Configuración segura de Windows Server.
* Análisis de controles de seguridad.

05. WSUS

* Administración centralizada de actualizaciones.
* Configuración de clientes mediante GPO.
* Verificación de conectividad y reportes.

06. Windows LAPS

* Administración de contraseñas locales.
* Configuración de políticas.
* Control de acceso y rotación de credenciales.

07. Troubleshooting

* Diagnóstico de servicios de Windows.
* Problemas de DNS y Active Directory.
* Errores de Group Policy y conectividad.

Metodología de documentación

Cada laboratorio incluirá:

1. Objetivo.
2. Requisitos y configuración del entorno.
3. Procedimiento paso a paso.
4. Comandos utilizados.
5. Evidencias fotográficas.
6. Resultados obtenidos.
7. Conclusiones y recomendaciones.

Objetivo profesional

Construir un portafolio técnico que demuestre conocimientos prácticos en administración de sistemas, seguridad de infraestructura, auditoría y protección de entornos empresariales.
